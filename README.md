##  Gameplay / Features

### Core Features

* Top Down Movement
* Interaction system
* Inventory System
* Dialogue System

### Controls

| Action | Keyboard  |
| ------ | --------- |
| Move   | `W/A/S/D` |
| Interact   | `Z`   |
| Open Inventory     | `C`   |
| Go Back | `X` |

##  How to Run

### Requirements

* Unity `6.x`
* Windows / Linux / macOS

### Installation

1. Clone the repository.

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

2. Open the project using Unity Hub.
3. Open the main scene.
4. Press **Play**.
